## Scripts

### `makeTS`

`makeTS` scaffolds a TypeScript project using `npm` and `git`.

Usage: `makeTS <project-name>`

Requirements:

- `npm` (Node.js Package Manager).
  - The command will not continue if `npm` is not installed.
- `git` (Git).
